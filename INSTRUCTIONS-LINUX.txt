🐧 WiFili Messenger (LanChat) - Linux Desktop Guide
========================================================================

Welcome to WiFili Messenger for Linux (Ubuntu, Debian, Fedora, Arch)!

------------------------------------------------------------------------
🚀 HOW TO RUN ON LINUX:
------------------------------------------------------------------------
1. Open terminal in this directory.
2. Make scripts executable:
   chmod +x run-desktop.sh run-web.sh
3. Run the desktop application:
   ./run-desktop.sh
   (or run: java -jar WiFili-Messenger-Desktop.jar)

------------------------------------------------------------------------
🛠️ TROUBLESHOOTING & TIPS:
------------------------------------------------------------------------
• Requires OpenJDK 17 or higher:
  Ubuntu/Debian: sudo apt install openjdk-17-jre
  Fedora:        sudo dnf install java-17-openjdk
  Arch Linux:    sudo pacman -S jdk17-openjdk
