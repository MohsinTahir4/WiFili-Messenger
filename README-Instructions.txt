📶 WiFili Messenger (LanChat) - Complete All-in-One PC Setup Guide
========================================================================

Thank you for downloading WiFili Messenger!
This package contains everything you need to run WiFili Messenger on your PC or Laptop.

------------------------------------------------------------------------
🚀 HOW TO USE (Simple 2 Steps):
------------------------------------------------------------------------

1. To open the Desktop Application:
   --> Double-click "1-Click-Start-Desktop-App.bat"

2. To open the Web Edition in Chrome or Edge:
   --> Double-click "1-Click-Start-Web-Browser-App.bat"

------------------------------------------------------------------------
💡 SYSTEM REQUIREMENTS & TIPS:
------------------------------------------------------------------------
• Requires Java 17 or higher. If Java is not installed on your PC,
  double-clicking the launcher script will automatically open the free 1-click
  official Java installer page at https://adoptium.net

• Connect all your devices (phones, laptops, PCs) to the SAME Wi-Fi router
  or Mobile Hotspot, then click "Scan LAN Users" to start chatting, file sharing,
  and audio/video calling 100% offline!

Enjoy 100% offline, private, high-speed Wi-Fi communication!
